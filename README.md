# تركي الحجاجي — Portfolio

موقع شخصي مهني باللغة العربية (RTL) يعرض الملف المهني، المشاريع، الشهادات والدورات، المهارات والخبرة ووسائل التواصل.

## نبذة

**تركي الحجاجي** — محلل بيانات وذكاء أعمال ونظم معلومات.

- بكالوريوس نظم معلومات — جامعة أم القرى
- الموقع: مكة المكرمة، السعودية
- المجالات: تحليل البيانات، ذكاء الأعمال، نظم المعلومات
- الأدوات الظاهرة في الموقع: Python، SQL، Excel، Power BI، Pandas، وغيرها حسب المشروع

## أقسام الموقع

- **الرئيسية:** التعريف المختصر والمهارات والأدوات ووسائل التواصل.
- **عنّي:** التعليم والموقع والنبذة المهنية.
- **المشاريع:** المشاريع التطبيقية ودراسات الحالة ومؤشرات الأداء وروابط GitHub المتاحة.
- **الشهادات والدورات:** عرض الشهادات كصور مصغرة مع إمكانية فتح ملف PDF.
- **المهارات:** المهارات التقنية والمهنية.
- **الخبرة:** الخبرات العملية المعروضة في الموقع.
- **تواصل:** نموذج تواصل يجهز رسالة واتساب، بالإضافة إلى البريد والهاتف وLinkedIn.

**المؤشرات المعروضة:**

- Orders: **1,500**

## التشغيل محليًا

الموقع عبارة عن ملفات HTML/CSS/JavaScript ثابتة، لذلك يمكن تشغيله مباشرة من خلال `index.html`.

ولأفضل تجربة أثناء التطوير يمكن استخدام أي Local Server مثل **VS Code Live Server**.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. تأكد أن `index.html` موجود في المسار المنشور.
3. من إعدادات المستودع فعّل **GitHub Pages** واختر الفرع والمجلد المناسبين.
4. ارفع مجلد `assets` كاملًا حتى لا تنكسر الصور أو ملفات الشهادات.
