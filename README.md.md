# Turki Al-Hajjaji — Portfolio

Personal portfolio website for **Turki Al-Hajjaji**, focused on Data Analysis, Business Intelligence, and Information Systems.

## Included

- Responsive portfolio layout for desktop, tablet, and mobile.
- Professional hero, profile, projects, skills, experience, and contact sections.
- Featured **Sales Performance & Profitability Analysis** case study with Power BI dashboard.
- Courses & Certificates section with certificate previews and original PDF files.
- Certificate categories are displayed as part of the certificate information; there is **no category filter bar**.
- Contact form integrated with Formspree.
- Smooth scrolling and lightweight interface animations.
- Back-to-top navigation support.
- Uses the provided portfolio content and certificate files.

## Main files

```text
index.html
style.css
script.js
assets/
├── sales-dashboard.png
└── certificates/
```

## Deployment

The project is a static website and can be deployed directly with GitHub Pages.

Upload the contents of this folder to the repository used by GitHub Pages. Keep the `assets` directory and its subfolders in the same relative location so images and certificate files continue to load correctly.
